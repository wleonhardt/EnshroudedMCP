# 0036: Global clearance evidence in read-only phase planning

Date: 2026-11-16. Status: implemented; private/public 339 Rust executions (including 18 repeated shared module checks), 57 Python tests, Clippy, formatting and release builds pass. Bounded native pure-preview and preservation checks pass; world occupancy and traversal remain unverified.

The phase compiler previously accepted a primitive's clearance argument through building_plan, then discarded that clearance report while extracting cells. Refuse per-module clearance with an instruction to use document-level clearance, so no requested constraint silently disappears. Existing requests without clearance keep the exact response shape and phase geometry.

Add optional document-level clearance with one to 32 absolute volumes using the existing native coordinates and dimensions. Admit half-metre world-bounded boxes, each at most 1,024 cells, before preview calls. Check each volume separately through the existing pure building_plan API; this preserves its per-request workload bound without limiting a whole phased structure to eight volumes. Require unchanged phase geometry and agreement with the independently computed requested-box/phase intersection. Missing or contradictory reports refuse.

Compute the final report over the complete exact union of all module/phase cells. A constraint occupied only in a later phase must report its exact conflicting cells. Preserve duplicate and overlapping requested volumes independently. Conflicts are reportable planning evidence, not a write gate or an executable plan. Generated phase plans remain geometry only; the global report is carried at document level and must be reviewed with the whole plan. It does not inspect current occupants or prove walkability, support, construction order or recovery.

Tests use a separate metre-space intersection oracle, exercise a later-phase-only conflict and half-open boundary, check compatibility without clearance, 32 volumes, malformed/off-grid/out-of-world/oversized boxes, dropped/contradictory reports and the per-module loss regression. Native checks preserve all existing cells and phase decomposition, compare the complete requested clearance set independently, detect an intentional final-phase conflict and verify immutable ledgers, installed hashes and absent flags. No runtime version, SDK pin, installed binary or gameplay state is changed.
