Date: 2026-11-16. Status: behavior tests and native pure-preview evidence pass; engine collision, avatar step-up and traversal remain unverified. No runtime or write change.

Decision 0045 checked only poses and connectivity. Retain those checks and add planned-cell intersections for a box translated linearly between admitted consecutive poses. A route is valid only when all poses have empty headspace and planned footing, all joins are connected, and every checked sweep is clear. Keep no-route output and phase geometry identical.

The existing restrictions make the cell computation small and exact: box extents and poses use half-metre integers, a join advances along one horizontal axis, and its vertical change is at most one cell. Every half-metre cell in the endpoint bounding hull has positive-volume intersection with the translated box at some time. Cells touching only the outer faces are excluded by half-open ranges. The newly reached top/bottom cell layers overlap during the open time interval, so testing hull cells does not introduce a conservative false-positive corner under these restrictions. Revisit this argument if diagonal joins, fractional cells or larger vertical deltas become admissible. At most 288 cells are considered per admitted join, bounded by the existing eight routes and 64 poses.

Report planned_sweep_clear and sweep_conflicting_cell_minima per join. Inadmissible joins are not checked and return null for both. The route aggregate is false for any known collision, null when a remaining join is unchecked without a known collision, and true only when all sweeps are checked and clear. Do not turn skipped work into empty/clear evidence.
