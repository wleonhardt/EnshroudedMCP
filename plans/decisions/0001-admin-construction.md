# Administrative construction first

Date: 2026-11-13. Status: accepted.

Implement survey, preview, gated placement, read-back and recovery before survival-cost accounting. The first proof is one tiny reversible fixture in an isolated world. Stable plan identity, bounded jobs and tested modules follow.

Administrative mode retains confirmation, a fresh write flag, journaling, game-thread scheduling, explicit protection checks and outcome reconciliation. It makes no inventory-consumption or progression claim.

The optional companion stays separate from the server mod and uses an explicitly experimental matching framework loader. Client event IDs never become server selectors, and current UI selection stays unknown without a verified reader.
