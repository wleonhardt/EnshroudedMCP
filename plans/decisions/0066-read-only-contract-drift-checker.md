# 0066: Check contract drift without executing advertised gameplay tools

Date: 2026-11-16. Status: source and local metadata-discovery checks qualified; no gameplay acceptance added.

Add scripts/check_contracts.py using the existing bounded loopback Client. Default execution is game-free: check unique scoped tools, counts, required schema/description/next-check fields, repository-relative source/evidence references, human table agreement and Cargo/toolchain profile versions. It does not parse Rust into schemas or independently derive SDK ABI offline. Python 3.11 or newer supplies the standard-library TOML parser; no package dependency is added.

Optional --server-port and --client-port select existing loopback endpoints. Compare the complete advertised name set, exact schemas and descriptions, ignoring list order but refusing duplicate names. Then call only the fixed metadata getter capabilities or client_capabilities, checking reported compiled mod version, SDK revision and ABI. Never choose executable tools from index data, run dry gameplay commands, create write flags, start processes or deploy binaries.

An offline consistent verdict means index/profile consistency; live_contracts_checked is empty. With requested endpoints it names only successfully checked scopes. native_behavior_verified and runtime_provider_verified remain false even when all comparisons pass. Compiled provenance is not native provider ABI/fidelity, applicability, rendering or persistence proof. Exit 0 means the requested checks are consistent, 1 means drift/invalid contract, and 2 means unavailable input/endpoint. No response payload is echoed for transport errors. The CLI reads no credentials; authenticated callers can pass an already configured Client to compare_live.

Nine behavior tests follow an initial missing-module failure. They cover valid index/table/source references, duplicate/scope/count/schema/next-check/reference failures, all four source-profile fields, reordered discovery, missing/unexpected/duplicate names, schema/description drift, reported compiled version/revision/ABI mismatch, capability errors, offline/no-network behavior, requested-endpoint dispatch and redacted unavailability. The fake endpoint fails if any call targets a gameplay tool; drift fails before executing capabilities where discovery already mismatches.

Offline and both local endpoint discovery checks pass for 36 server and 13 companion contracts. Complete private/public product checks pass 373 Rust executions, 80 Python tests, strict Clippy, formatting and both releases. The Rust package versions/SDK pins and installed 0.45.0/0.20.2 remain unchanged. This is a helper and documentation increment; it adds no mod tool, provider adoption or native gameplay acceptance.

While connecting operational documentation, remove the stale 32-tool count, queued/uninstalled reposition-observer statements, old test counts and active SDK-patch guidance. Preserve the historical exact-return failure and refer to the matrix for current operational scope. Source fixtures and exact compiled provenance remain separate from the unqualified runtime-provider and live workflow gates.
