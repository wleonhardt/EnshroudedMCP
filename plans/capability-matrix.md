## Profiles and evidence rules

Product source and installed versions are server **0.45.0** and companion **0.20.2**, official SDK `6a151a9550ed7a6ade99c23fa817a91e25b71bc9`, ABI **12.1**, Rust **1.99.1**. Later test-only and qualification-document edits do not imply new installed DLLs. Inactive SDK `9f6efc821524df426991fb584a761eaa0e5ea898` / ABI **12.8** / Rust **1.100.0** is separately source-qualified; no matching native provider is qualified or installed.

[Machine-readable contracts](capability-contracts.json) preserve all 49 advertised input schemas, descriptions, definition/dispatch references, thread ownership, admission, evidence limits and next checks. Inventory was compared with the running endpoints' tools/list and source tool definitions on this date: 36 server and 13 companion tools. Schemas describe argument bounds; policy checks add semantic bounds and reject unnamed arguments. Discovery does not prove an executor is currently available.

Loopback transport and published API restrictions apply throughout. World access uses the server game-thread scheduler. Companion observation copies client-frame data; archive requests run on the UI frame, while SDK commands execute in the later native client phase. Copied snapshots and retained reports may be read on the listener. Output limits do not bound all SDK discovery/allocation work. Session entity IDs are not persistent identities.

Write-bearing branches require their existing policy gate, fresh regular ALLOW_WRITES, confirmation, journal and applicable once-only/session checks. Read-only or dry branches do not grant mutation authority. Unknown outcomes are never automatically retried. Join, logout, process lifecycle, screenshots and crafting execution remain unsupported native capabilities. Windows MCP/capture remain off.

Source tests, positive native outcomes, tested refusals, independently observed effects, rendered behavior, persistence and freshness/completeness are separate acceptance dimensions. The JSON explicitly leaves unreconciled historical evidence open rather than manufacturing a pass from a fixed-shape smoke probe. Goal 1 remains open until every tool has dated behavior-level evidence and a precise missing test.
