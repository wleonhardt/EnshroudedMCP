# Curated knowledge

Updated: 2026-11-16. Use [the capability matrix](../capability-matrix.md) for current implementation, evidence limits and next checks. `knowledge_search` is implemented; `knowledge_read` is a distinct scoped native observation and never proves crafting eligibility.

`claims.json` contains provenance-bearing research statements consumed by `knowledge_search` through `include_str!`. Changing evidence requires rebuilding. Source observations, historical documentation, hypotheses and narrow live observations remain distinct.

Claims cannot authorize writes or weaken game-free policy. Recipe plans remain conditional on supplied data. Current-world reads, eligibility, material mapping and persistence need their own verified evidence.
