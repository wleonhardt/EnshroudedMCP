# Project plans

Project knowledge lives here. Keep credentials, private infrastructure, player identities and raw runtime data outside the repository.

| Path | Purpose |
| --- | --- |
| `goal.md` | Administrative construction sequence and acceptance |
| `next-up.md` | Current queue and verified work |
| `open-questions.md` | Unresolved API and live-validation questions |
| `decisions/` | Settled implementation choices |
| `knowledge/` | Curated evidence consumed at build time |
| `research/live-validation.md` | Sanitized isolated findings and limits |

Use absolute dates. Distinguish implemented, tested offline, observed live and pending acceptance. Unknown data remains unknown.
