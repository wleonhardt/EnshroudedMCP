# Native persistence-rule fixture

Server 0.23.0 provides `building_access` for explicitly supplied site boxes. This isolated read-only fixture investigated the native zone rule before further construction planning. It did not place anything or join an actor.

The experiment began with a known half-metre box for which the native persistence rule returned true. Six axis profiles sampled outward at eight-metre intervals up to 64 metres. Local bisection near the first false coarse sample found adjacent true/false observations at half-metre resolution. Both bracket endpoints were queried again and agreed. Eighty-five requests covered the profiles. Coarse samples contained no false-to-true reversal, but unsampled transitions were not excluded.

Axis samples do not prove the enclosed volume. Seven separate requests queried the combined inner box directly, then expanded each of its six faces independently. The 39-by-39-by-39-metre inner box returned true. Every single-face half-metre expansion returned false. All requests remained within the tool's 64-metre side limit and the same observed world key. These measurements describe one fixture, not every base or altar upgrade.

All 92 calls omitted the actor selector and returned unrequested/null build rights. The journal stayed unchanged. Complete prior voxel captures, operation-ledger membership/hashes, companion journal and installed binaries remained exact. Zero players, disabled writes and unchanged research settings were checked before and after.

The result supplies a directly queried candidate volume for later planning. It does not establish collision, terrain clearance, ground contact, an item's full placement footprint, saved contents or actual save/reload effects. Current native rule reads must be repeated before relying on a box; this record is not executable policy or write authorization. Overlapping bases, upgraded zones, native failure cases and a loaded construction-preview comparison need separate acceptance.

See [tool arguments](tool-reference.md) and the pinned framework's published [native build checks](https://github.com/enshwick/enshwick/blob/acd5550c607a38c983433f9807cc95564244fe0b/crates/internal/world/src/world/build.rs). Private coordinates, complete raw observations and recovery artifacts are excluded from publication.
